Задание 1. Безопасность и "секретное слово" (Легкое)
Что нужно сделать:Сейчас функция «Забыл пароль» (forgot_password) просто выдает пароль любому, кто ввел логин. Это небезопасно.
Нужно изменить процесс регистрации и восстановления:
1) В метод register() добавить новый запрос: пусть пользователь придумывает не только пароль, но и секретное слово (например, девичью фамилию матери или кличку питомца). Сохранять это слово в словарь self.users (подсказка: теперь в значении словаря может быть список [пароль, секретное слово] или нужно создать второй словарь self.secret_words = {}).
2) В методе forgot_password() перед тем, как показать пароль, программа должна спросить это секретное слово. Если оно верное — показать пароль, если нет — выдать ошибку.

Задание 2. "Три попытки на вход" (Среднее) 
Что нужно сделать: Если пользователь вводит пароль неправильно много раз, его нужно заблокировать. 
1) В метод login() добавить счетчик попыток (цикл while или счетчик внутри метода, позволяющий ошибиться не более 3 раз подряд).
Если пользователь 3 раза ввел неверный пароль, программа должна написать: «❌ Аккаунт заблокирован! Попробуйте позже» и принудительно вернуть его в Главное меню (или вообще закрыть программу через break).

Задание 3. "Админ-панель и просмотр базы" (Интересное) 
Что нужно сделать: В коде уже есть предустановленный пользователь "admin". 
Нужно сделать так, чтобы админ мог видеть всех зарегистрированных пользователей. 
1) В Главное меню (метод start) добавить новый пункт: «5. Админ-панель (только для admin)». Если обычный пользователь выбирает пункт 5, программа должна сказать: «❌ Отказано в доступе! Вы не админ».

3) Если вошел admin и выбрал пункт 5, программа должна красиво вывести на экран список всех логинов, которые сейчас есть в базе self.users
