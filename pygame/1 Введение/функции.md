# pygame.draw.rect(surface, color, rect, width=0) — Прямоугольник.
	• rect: Координаты и размеры (x, y, ширина, высота).
	• width: 0 — закрашенный (по умолчанию), > 0 — толщина рамки.
# pygame.draw.polygon(surface, color, points, width=0) — Многоугольник.
	• points: Список точек-вершин [(x1, y1), (x2, y2), (x3, y3), ...].
# pygame.draw.circle(surface, color, center, radius, width=0) — Круг.
	• center: Центр круга (x, y).
	• radius: Радиус (число).
# pygame.draw.ellipse(surface, color, rect, width=0) — Эллипс.
	• rect: Прямоугольник (x, y, ширина, высота), в который вписывается эллипс.
# pygame.draw.line(surface, color, start_pos, end_pos, width=1) — Отрезок.
	• start_pos: Точка начала (x, y).
	• end_pos: Точка конца (x, y).
	• width: Толщина линии (по умолчанию 1).
# pygame.draw.lines(surface, color, closed, points, width=1) — Ломаная линия.
	• closed: True — соединить первую и последнюю точки, False — оставить открытой.
	• points: Список последовательных точек [(x1, y1), (x2, y2), ...].
